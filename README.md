# Minimal Academic Website

A minimal bilingual-friendly academic website starter using GitHub Pages, Jekyll,
and MathJax.

## Setup

1. Create a repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload all files in this folder to the repository root.
3. Edit `_config.yml`: replace `YOUR-GITHUB-USERNAME` and `Your Name`.
4. Edit the profile, research, and publication pages.
5. In GitHub, open **Settings → Pages** and select **Deploy from a branch**,
   branch `main`, folder `/ (root)`.
6. Visit `https://YOUR-GITHUB-USERNAME.github.io`.

MathJax supports LaTeX delimiters `\(...\)` for inline math and `$$...$$`
for display math. The `notes/` Markdown pages are rendered by Jekyll as webpages.

If you use the `minima` theme, remove the custom `_layouts/` folder only if you
want to return to the theme's built-in layouts. This starter includes its own
simple layouts and stylesheet.
